A Lei Geral de Proteção de Dados (LGPD) não é só para grandes empresas. Clínicas de estética e salões lidam com dados pessoais sensíveis e estão sujeitos à lei.

## Os direitos do titular

Todo cliente tem direito a:

- **Acesso**: saber quais dados você tem sobre ele.
- **Exportação**: receber esses dados em formato legível.
- **Correção**: pedir correção de dados incorretos.
- **Anonimização**: ter seus dados pessoais removidos.
- **Exclusão**: solicitar a eliminação dos dados.

A LGPD dá prazo de até 15 dias para atender essas solicitações.

## O que isso significa na prática

Se um cliente pedir a exportação dos dados, você precisa entregar um arquivo com as informações dele. Se pedir anonimização, os dados pessoais devem ser removidos sem apagar o histórico de atendimentos.
